# Math Arcade

A study game for Math 3800 Test 2 (discrete and continuous distributions, §3.4–4.4),
made for a Galaxy Tab with an S Pen. Every level is a line from the class review list;
a right answer plays an animation that works the problem out.

## Run it

    python3 serve.py          # http://localhost:8380, or http://<this computer's IP>:8380 on a tablet
    python3 serve.py 9000     # another port

`serve.py` tells browsers not to keep stale copies, so a refresh always gets the latest
`index.html`. Progress is saved in each browser.

## What's in it

- **World 0 · The tree** — name the distribution for a story, picked from a list of all ten
  with their formulas. A right answer plugs the story's numbers into the formula, works
  every piece out (C(n, x), x!, Γ(α), the table lookup), boxes the answer and draws the
  distribution. Test mode has harder, test-style stories, each with a trap.
- **Worlds 1–4** — tables, plug-in problems, the derivation scripts and the calculus,
  generated by the MathReps question engine. A right answer shows the work step by step,
  with the question's numbers linked to where they land, the table lookup and a graph
  when the question names a distribution. Each world ends with a review level.
- **World 5 · Everything** — one question from every level.
- **Final boss** — one written question per level, graded after you hand it in.
- **Paper mode** — every level without choices, for double XP.
- **S Pen ink** — write anywhere with the pen; fingers still scroll. Click the side button
  (or tap three times in one spot) to switch to the eraser and back. Open the page with
  `#pen` to see what the pen reports.

## Files

- `index.html` — the whole game.
- `engine.js` — a bundle of the MathReps Test 2 question generators (from the
  Math-380-test repo at commit 1fcb54b): `window.Test2`.
- `serve.py` — the local server.
